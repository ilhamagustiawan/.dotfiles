# Engineering

Engineering workflows imported from [mattpocock/skills](https://github.com/mattpocock/skills), with pinned-source updates and local adaptations documented in [SOURCES.md](../SOURCES.md).

## User-invoked

- **[implement](implement/SKILL.md)**: Implement a spec or set of tickets.
- **[implement-spec](implement-spec/SKILL.md)**: Implement the output of `to-spec` and `to-tickets`.
- **[retro](retro/SKILL.md)**: Review a coding session for lessons.
- **[setup-engineering-skills](setup-engineering-skills/SKILL.md)**: Configure project tracker and domain documentation conventions.
- **[to-spec](to-spec/SKILL.md)**: Synthesize the conversation into a spec.
- **[to-tickets](to-tickets/SKILL.md)**: Break work into tracer-bullet tickets with dependencies.
- **[wayfinder](wayfinder/SKILL.md)**: Map and resolve decisions across a large effort.
