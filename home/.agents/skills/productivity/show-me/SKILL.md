# Show me

Help the user understand the current topic visually. Read [visual guidance](VISUAL-GUIDANCE.md), choose the smallest useful view, and keep prose brief.

For a visual UI, layout, state comparison, or concept too dense for a text diagram, create one focused HTML file when the active mode and permissions allow it. Match the product's colors, type, spacing, and components; use real labels and data, and support desktop and mobile. Open it with the host's available file-opening tool or command when permitted; otherwise provide its path. In a read-only or restricted mode, use an inline visual or ask before creating an artifact.
